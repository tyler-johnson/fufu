Takes the name off the list. fufu stops describing the extension — its verbs leave the tool and the card, `ff help <name>` stops reaching the binary, its briefing line and its skills and its subscriptions all stop being fufu's business.

Nothing is uninstalled. `ff-<name>` is still on PATH and `ff <name>` still runs it, on the same three variables it always had. Skills a `ff hook` install already wrote stay where they were written; the next install is what stops carrying them.

A name that was never declared is refused rather than answered as done. `ff undo` does not reach any of this either: the list is per machine and lives outside every repository, so the way back is `ff extension add <name>` again.

## Examples

```
ff extension remove tower    fufu stops describing it
ff extension list            what is left
ff extension add tower       declare it again
```

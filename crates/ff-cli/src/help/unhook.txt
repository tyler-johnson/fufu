Removes exactly what `ff hook` added, and nothing else. Foreign entries
in a settings file keep whatever shape they had; a line somebody wrote
by hand is left where it is and reported rather than removed. The
directories fufu owns outright — the Claude plugin, and the skill each
client that reads one was given — go whole, because there is nothing
else in them.

Bare `ff unhook` reports and asks, the same way `ff hook` does.

Examples:
  ff unhook claude         one client
  ff unhook --all          everything fufu wired
  ff hook -l               what is wired, before and after

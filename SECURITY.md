# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/tyler-johnson/fufu/security/advisories/new): a private channel to the maintainer, with no public issue until a fix ships. Please do not open public issues for security reports.

The latest release is the supported release; fixes land at the tip. The install page covers [pinning and verifying](https://tyler-johnson.github.io/fufu/install/#pin-and-verify) a release artifact.

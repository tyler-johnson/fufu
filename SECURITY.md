# Security

Report vulnerabilities privately to the maintainer through [GitHub private vulnerability reporting](https://github.com/tyler-johnson/fufu/security/advisories/new). Please do not open public issues for security reports.

Only the latest release is supported. Fixes are included in new releases and are not backported. The install page covers [pinning and verifying](https://tyler-johnson.github.io/fufu/install/#pin-and-verify) a release artifact.
